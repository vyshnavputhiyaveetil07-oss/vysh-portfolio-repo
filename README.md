## 🛠️ Project Structure
```text
src/
├── components/
│   ├── Background3DCanvas.tsx   # Light-theme 3D WebGL background canvas
│   ├── DigitalResume.tsx        # Main single-page digital resume container
│   ├── SEO.tsx                  # Document title, metadata & Schema.org JSON-LD
│   └── SocialIcons.tsx          # SVG icons for GitHub & LinkedIn
├── data/
│   ├── profile.ts               # Candidate metadata & verified contacts
│   ├── projects.ts              # 8 practical & 2 academic project case studies
│   ├── skills.ts                # Verified skills & 3D tool code snippets
│   ├── timeline.ts              # Verified career timeline (BCom -> MSc Greenwich)
│   └── cvData.ts                # Structured CV content payload
└── types/
    └── portfolio.ts             # TypeScript interface definitions
```

## 💻 Running Locally

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```
